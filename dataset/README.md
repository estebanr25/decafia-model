\# Dataset DECAFIA



El dataset completo no está disponible públicamente debido a derechos 

institucionales (Universidad Industrial de Santander - UIS).



\## Estadísticas



\- 2,786 imágenes de campo real

\- Finca en El Socorro, Santander, Colombia

\- 12,810 instancias anotadas

\- Clases: Roya, Coco, Minador, Sano
